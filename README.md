# HR-Analytics-PowerBI-Dashboard

## Overview

This project presents an interactive HR Analytics Dashboard developed using Power BI to analyze employee data and key workforce metrics.

## 📄 Dashboard PDF

Click below to view the complete dashboard:

[📥 View HR Analytics Dashboard (PDF)](HR_Analytics_Dashboard.pdf)

## Features

- Cleaned and transformed data using Power Query
- Created DAX measures for HR KPIs
- Interactive slicers and filters
- Employee demographics analysis
- Department-wise attrition analysis
- Salary and experience insights

## KPIs

- Employee Headcount
- Attrition Count
- Attrition Rate
- Retention Rate
- Average Age
- Average Tenure
- Average Salary

## Tools

- Power BI
- Power Query
- DAX
- Microsoft Excel
